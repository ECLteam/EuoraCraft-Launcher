# 语言选择器中性文字标签实施方案（已确认实施）

## 需求与现状

- 目标：语言下拉框及当前选中值不再显示任何旗帜，避免旗帜 emoji 在不同系统上的外观差异和不合适的地区联想。
- 当前 `frontend/src/i18n/index.ts` 的六个语言条目都含有 `flag` emoji；`frontend/src/views/settings/LauncherTab.vue` 将 `flag` 与 `name` 拼接成 `NSelect` 选项标签。
- `supportedLocales` 的其他调用只读取 `code`；已保存的语言配置也是 `zh-CN`、`zh-TW` 等代码，与选项的显示文字分离。

## 方案比较与选择

| 方案 | 显示示例 | 取舍 |
| --- | --- | --- |
| A. 仅显示名称 | `简体中文`、`繁體中文`、`English` | 最简洁；没有额外的快速识别标记。 |
| B. 名称前加普通文字缩写（用户已选择） | `简  简体中文`、`繁  繁體中文`、`EN  English` | 保留选项前部的快速识别位置，不依赖旗帜 emoji 或图像资源。 |

## 文字映射

| 语言代码 | 缩写 | 语言名称 |
| --- | --- | --- |
| `zh-CN` | `简` | 简体中文 |
| `zh-TW` | `繁` | 繁體中文 |
| `en-US` | `EN` | English |
| `ja-JP` | `JA` | 日本語 |
| `ru-RU` | `RU` | Русский |
| `de-DE` | `DE` | Deutsch |

缩写只用于显示；持久化代码和语言加载逻辑保持现有行为。选项与选中值都通过同一标签显示。

## 实施步骤

1. 在 `frontend/src/i18n/index.ts` 将 `supportedLocales` 的 `flag` 字段替换为 `shortLabel`，使用上表的普通文本。
2. 在 `frontend/src/views/settings/LauncherTab.vue` 使用 `shortLabel` 与 `name` 生成下拉选项标签，不引入额外图标、字体或图片资源。
3. 检索前端所有 `flag`、区域旗帜字符与语言选项消费位置，确保没有剩余的语言旗帜显示路径。
4. 运行 `pnpm check` 和 `pnpm build`；实际启动启动器，检查下拉选项与当前选中值，并切换至少一种语言确认语言保存功能可用。
5. 检查 Git 变更后，仅提交本功能对应的前端文件和主仓库子模块指针，不推送远端。

## 验收标准

- 六个语言选项及当前选中值均显示普通文字缩写和语言名称，不含旗帜 emoji。
- 简体中文与繁体中文明确区分；原有 `zh-CN` / `zh-TW` 配置值和语言切换结果不变。
- 浏览器展示模式和桌面模式使用相同的文字标签，不依赖系统 emoji 字体。

## 实施与验证记录

- 已将六个语言条目的 `flag` 替换为 `shortLabel`，并让下拉选项使用缩写与名称；语言代码和保存逻辑未变。
- `pnpm check` 通过：91 个测试文件通过，378 个测试通过，1 个待办。
- `pnpm build` 通过。
- 使用隔离数据目录启动桌面版：当前值和六个下拉选项均显示文字缩写；切换为 English 后界面立即更新，配置保存为 `en-US`；随后正常退出。
